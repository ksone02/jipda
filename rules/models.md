# 모델 분담

| 일 | 1순위 | 안 되면 |
|---|---|---|
| 넓게 검색, 원문 읽기 | DeepSeek (`scripts/ext.py deepseek`) | Claude haiku 하위 에이전트 |
| 대조 검사, 실행 검증, 반박 | Codex (`scripts/ext.py codex`) | Claude 하위 에이전트, 독립성 조건 |
| 전문가 역할 검토 | Claude sonnet(큰 설계 판단은 opus) | — |
| 구체화, 설계, 종합 | 메인 세션 | — |
| 반복 구현 | 아래 등급표 | — |

## 외부 모델 부르기
- 명령: `python3 <플러그인 폴더>/scripts/ext.py <codex|deepseek> --root <저장소> --timeout 540 --prompt-file <프롬프트> [파일...]`. 플러그인 폴더는 스킬 폴더의 두 단계 위예요.
- Bash 도구는 `timeout: 600000`으로 불러요. 스크립트가 먼저 끝나야 `STATUS:` 줄이 남아요.
- 서로 독립인 호출은 함께 돌려도 돼요.
- 출력 첫 줄이 `STATUS: unavailable` 또는 `STATUS: banned`이면 위 표의 "안 되면"으로 넘어가고, 아래 대체 문구를 결과 첫 줄에 써요.

## 등급표
가장 싼 모델은 여러 단계 작업에서 턴을 2~3배 써서 총비용이 더 클 수 있어요.
- **haiku**: 계획에 쓸 코드가 다 들어 있는 옮겨 적기와 시험, 한 파일 기계적 수정, 검색 대체.
- **sonnet**: 설명만 보고 구현, 여러 파일, 모든 검토자의 최소 등급.
- **opus**: 설계 판단, 마지막 브랜치 전체 검토, 수정이 3회 넘게 막혀 올리는 경우.
- 하위 에이전트를 띄울 때는 Agent 도구의 `model`을 꼭 적어요. 빠뜨리면 비싼 세션 모델을 물려받아요.

## Claude로 검증할 때의 독립성 조건
- 메인 대화를 물려받지 않은 새 하위 에이전트.
- 완료 조건과 결과물만 주고, 만든 쪽의 생각 과정은 주지 않아요.
- 만든 모델과 다른 등급(만든 쪽이 sonnet이면 opus).

## 대체했을 때 결과 첫 줄
- `Codex 사용 불가, Claude로 검증`
- `DeepSeek 사용 불가, Claude로 조사`
- 이유(설치 안 됨, 사용량 한도, 시간 초과, 외부 AI 금지 프로젝트)를 괄호로 붙여요.
