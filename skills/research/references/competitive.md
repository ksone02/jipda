# Competitive analysis

1. **Write the decision and questions.** What will this analysis decide? Turn it into a few questions and map each to sources.
2. **Find the real alternatives.** Ask: what would a customer do if this did not exist? Include doing nothing, a spreadsheet, and hiring a person. Drop famous names customers would never actually compare.
3. **Pick the analysis yourself.** Match it to the decision, at most 2. Say which in one line and start; do not ask the user to choose.

| Question | Analysis | Output |
|---|---|---|
| Is this market structurally attractive? | Five forces | Pressure from rivals, customers, suppliers, new entrants, substitutes |
| What is each one good at? | Profile table | 3-5 competitors × 8-10 factors customers care about |
| Where is the gap? | Value curve | Factor ratings per competitor, then eliminate/reduce/raise/create |
| How should we be different? | Positioning | Alternatives → differentiators → value → best-fit customers → category |
| Why do people pick or leave? | Review analysis | Coded reasons from reviews and community posts |

4. **Collect evidence, labeled by strength.**
   - Direct: use the product, screenshots, pricing pages, changelogs.
   - People: reviews, forums, comparison threads.
   - Inference only: job postings, as a hint of investment direction.
   - Filings and earnings calls for public companies.
   Use public information only. No deception, unauthorized access, or inducing someone to break an NDA.
5. **End with what to do.** Copy what, deliberately skip what, and which open position to take. Comparison without a choice breeds imitation.

For screen references, open 3-5 sites, analyze structure only, and do not copy code or copy text.
