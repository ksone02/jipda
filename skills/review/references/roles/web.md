# Web service

## Product planner
Must check:
- User flows missing from the done conditions
- Exception flows: empty data, no permission, failure, going back
- Does the user know what to do on the first screen
- Does the scope fit the deadline

## Designer
Must check:
- `rules/ui.md` Tier 1 violations
- States (loading, error, empty, disabled)
- Information hierarchy: is the most important thing seen first
- Does the copy follow the writing rules for its language

## Senior frontend developer
Must check:
- Accessibility: keyboard, focus, contrast, screen reader names
- Performance: large data, unnecessary rerenders, bundle size
- Responsiveness: 1440, 1366×768, and 390 widths
- State management and data-loading failure handling
