# Connection methods

Use the one matching why the ideas feel obvious. Produce concrete candidates, then return to [ideation.md](ideation.md) to narrow.

## Many parts could combine: morphological box
1. List the problem's independent parameters.
2. List options for each, in a grid.
3. Remove combinations that cannot work together.
4. Pull out unusual combinations that survive.

## Work with what exists: inventive patterns
Stay within the elements already in the problem and apply each:
- **Subtract** a core part, then find what the remainder could do.
- **Multiply** a part, changing the copy.
- **Divide** it and rearrange the pieces.
- **Give a task** to an existing resource.
- **Link or unlink** two variables that were independent or dependent.

## Improving A worsens B: resolve the contradiction
1. State it: improving this makes that worse.
2. Describe the ideal result where the benefit arrives with no cost.
3. Find how to separate the two, in time, space, or by condition. Do not settle for a compromise first.

## Only familiar answers: analogy
1. Ask how a distant field solves the same underlying problem.
2. Make the familiar strange: state the problem through that analogy.
3. Bring back what could work and turn it into a real action.
