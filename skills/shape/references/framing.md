# Issue tree with hypotheses

Use when the problem is fuzzy or large.

1. **Lock one problem sentence.** Specific and answerable, with the decision it serves. Confirm it with the user.
2. **Break it into a question tree,** usually 2-3 levels. For each set of siblings ask "do these overlap?" and "what is missing?" Stop when a branch is something one person could investigate in about a week.
3. **Prioritize the leaves.** Keep the ones that would change the decision most.
4. **Turn top leaves into hypotheses,** starting from your best guess at the answer. For each, write the evidence that would prove it and the evidence that would kill it.
5. **Show:** the tree, then a table of `hypothesis | proves it | kills it | cheapest way to check`.
