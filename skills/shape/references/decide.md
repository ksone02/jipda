# Deciding and writing it up

## Quick screen, then weighted
1. Pick a baseline option.
2. Rate each alternative on each criterion as better, same, or worse than the baseline.
3. Combine the strongest parts of good options into a hybrid.
4. Only for the finalists: weight the criteria, score, and multiply. Treat a close result as a tie, then decide on what is most important.
State must-haves first; an option missing one is out.

## Pre-mortem and assumptions
1. Assume it has already failed. Write the plausible reasons.
2. Turn those into assumptions.
3. Rank by how likely to be wrong and how much it would hurt.
4. For the top one, name the cheapest test.

## One-page form
Start with the conclusion, then key reasons, then evidence. Skip evidence the reasons already justify.
1. Conclusion: what to build, for whom
2. Why: 2-4 key reasons
3. Not doing
4. Riskiest assumption and how it gets tested
5. Done conditions
