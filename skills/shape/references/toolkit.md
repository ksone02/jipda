# Planning toolkit

Find what blocks the idea, offer the fitting tools, and let the user pick. Read only the chosen tool's file.

| What is blocking | Tool | File |

| The future could go several ways | Scenarios | [strategy.md](strategy.md) |
| What exactly to build and why | Press release and FAQ | [product.md](product.md) |
| Many customer problems, which first | Opportunity tree | [product.md](product.md) |
| Is it big enough | Market sizing | [market.md](market.md) |
| Who exactly it is for | Needs-based segments | [market.md](market.md) |
| Ideas feel obvious | Connection methods | [creative.md](creative.md) |
| Choosing among options | Quick screen, then weighted | [decide.md](decide.md) |
| It could fail | Pre-mortem and assumptions | [decide.md](decide.md) |
