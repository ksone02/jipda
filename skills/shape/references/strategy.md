# Strategy tools

## Where to play and how to win
Treat these as a pair, never in sequence.
1. Propose a place to compete (customers, use, channel) together with how to win there.
2. If the pair does not win, change the place. If it still does not, discard it and try another. Do not keep long lists of places.
3. Reality check: can the capabilities and way of working actually deliver this pair?
4. State where you will **not** play. No exclusion means no choice was made.
5. Ask of the chosen pair: what would have to be true for this to work? List those conditions and test the shakiest first.

Show: `where | how to win | can we deliver | what must be true`.

## Value curve and four actions
1. List the factors the field competes on.
2. Rate what buyers get on each factor, for each alternative. Each alternative's line is its value curve.
3. Ask four questions: which factors should be **eliminated**, which **reduced** well below the standard, which **raised** well above it, and what should be **created** that the field has never offered.
4. Draw the new curve. If it looks like everyone else's, it is not a different strategy.

Show: the factor table and the four-action grid.

## Scenarios
Use when outcomes depend on things you cannot control.
1. List drivers of change. Keep only those with significantly different possible outcomes; predictable ones are assumptions.
2. Combine them into 7-9 short scenarios, then reduce to 2-3. More overcomplicates the analysis.
3. Write each scenario, then the issues it raises.
4. Find the moves that work in every scenario and the ones that bet on one.

Show: `scenario | what happens | what we would do`, and the moves that hold across all.
